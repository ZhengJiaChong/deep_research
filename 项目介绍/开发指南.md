### 添加新的搜索源

**涉及文件**：`backend/app/services/new_search_service.py`, `backend/app/workflow/nodes.py`, `backend/.env`

#### 步骤1：创建搜索服务

```python
# services/new_search_service.py

from app.utils.logger import get_logger

logger = get_logger("NewSearchService")

class NewSearchService:
    """新搜索引擎封装"""
    
    def __init__(self):
        self.api_key = os.getenv("NEW_SEARCH_API_KEY")
        self.client = NewSearchClient(self.api_key)
    
    async def search(self, query: str) -> List[Dict]:
        """执行搜索"""
        results = await self.client.search(query)
        
        return [
            {
                'title': r.title,
                'url': r.url,
                'content': r.snippet,
                'source': 'new_search'
            }
            for r in results
        ]
```

#### 步骤2：集成到现有流程

**修改文件**：`backend/app/workflow/nodes.py`

```python
# workflow/nodes.py

from app.services.new_search_service import NewSearchService

new_search = NewSearchService()

async def execute_tasks_parallel_node(state: ResearchState):
    tasks = state['tasks']
    
    for task in tasks:
        # Tavily搜索
        tavily_results = await search_service.search(task['keywords'])
        
        # 新搜索引擎
        new_results = await new_search.search(task['keywords'])
        
        # 合并结果
        all_results = tavily_results + new_results
        task['search_results'] = deduplicate_results(all_results)
```

```python
# api/skills_router.py

@router.post("/execute/{skill_name}")
async def execute_skill(skill_name: str, params: dict):
    """执行指定技能"""
    
    skill_path = f"app/skills/{skill_name}/scripts/validate.py"
    
    if not os.path.exists(skill_path):
        raise HTTPException(404, f"Skill '{skill_name}' not found")

    return result
```

## 🚀 部署指南

**涉及文件**：`Dockerfile`, `docker-compose.yml`, `nginx.conf`

### Docker部署

#### Dockerfile

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# 安装依赖
COPY backend/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY backend/ .

# 暴露端口
EXPOSE 8000

# 启动服务
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

#### docker-compose.yml

```yaml
version: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    env_file:
      - ./backend/.env
    volumes:
      - ./logs:/app/logs
  
  frontend:
    build: ./frontend
    ports:
      - "80:80"
    depends_on:
      - backend
```

### Nginx配置

```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    # 前端静态文件
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }
    
    # 后端API代理
    location /api/ {
        proxy_pass http://backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        
        # SSE支持
        proxy_buffering off;
        proxy_cache off;
        chunked_transfer_encoding on;
    }
}
```

```python
from prometheus_client import Counter, Histogram

RESEARCH_COUNTER = Counter(
    'research_total',
    'Total research count',
    ['status']
)

RESEARCH_DURATION = Histogram(
    'research_duration_seconds',
    'Research duration'
)

# 使用
async def start_research(query):
    with RESEARCH_DURATION.time():
        try:
            # 业务逻辑
            RESEARCH_COUNTER.labels(status='success').inc()
        except Exception:
            RESEARCH_COUNTER.labels(status='error').inc()
```

### 4. 输入验证

```python
from pydantic import BaseModel, Field

class StartResearchRequest(BaseModel):
    query: str = Field(..., min_length=5, max_length=500)
    
    @validator('query')
    def validate_query(cls, v):
        if not v.strip():
            raise ValueError("Query cannot be empty")
        return v.strip()
```
