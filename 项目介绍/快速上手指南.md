## 🚀 一键启动

**涉及文件**：`start.bat`, `backend/app/main.py`, `frontend/package.json`

### Windows用户

```bash
# 双击运行启动脚本
start.bat
```

### 手动启动

```bash
# 终端1：启动后端
cd backend
python -m app.main

# 终端2：启动前端
cd frontend
npm run dev
```

访问地址：
- 前端：http://localhost:5173
- 后端API文档：http://localhost:8000/docs

## 🔑 配置API密钥（首次使用）

**涉及文件**：`backend/.env`, `backend/.env.example`, `backend/app/config.py`

### 步骤1：创建.env文件

```bash
cd backend
cp .env.example .env
```

### 步骤2：编辑.env

**配置文件**：`backend/.env`

```env
# OpenRouter API密钥（必填）
JWZT_OPENROUTER_API_KEY=sk-or-v1-your-key-here

# Tavily搜索密钥（必填）
JWZT_TAVILY_API_KEY=tvly-dev-your-key-here
```

### 步骤3：获取密钥

- **OpenRouter**: https://openrouter.ai/keys
- **Tavily**: https://app.tavily.com/home

## 📖 使用流程

```mermaid
graph LR
    A[输入问题] --> B[等待分析]
    B --> C[查看大纲]
    C --> D[观察进度]
    D --> E[阅读报告]
```

### 1. 输入研究问题

在首页输入框输入具体问题，例如：
- "人工智能在医疗领域的应用现状"
- "新能源汽车电池技术发展趋势"
- "中国电商市场格局分析"

### 2. 语义分析（5秒）

系统自动提取：
- 核心研究领域
- 关键概念
- 研究维度

### 3. 生成大纲（10秒）

自动生成5-8个研究任务：
1. 行业背景与定义
2. 市场规模与增长
3. 主要参与者分析
4. 技术发展趋势
5. 政策环境影响
6. 挑战与机遇

### 4. 执行研究（30-60秒）

每个任务并行执行：
- 生成搜索关键词
- Tavily深度搜索
- LLM分析结果

### 5. 生成报告（10-30秒）

流式输出完整研究报告：
- Markdown格式
- 引用标记 [1][2][3]
- 可点击引用链接

## 🛠️ 常见问题

### Q1: 研究卡在某个任务不动？

**检查文件**：`backend/app/services/llm_service.py`, `backend/logs/app.log`

**原因**：LLM API响应超时  
**解决**：
1. 检查网络连接
2. 确认API密钥有效
3. 刷新页面重试

### Q2: 报告没有引用标记？

**检查文件**：`backend/app/workflow/nodes.py`, `backend/app/api/research.py:126-200`

**检查**：
1. 确认搜索结果不为空
2. 查看浏览器控制台日志
3. 检查`citations`数据是否传递

### Q3: 流式输出中断？

**检查文件**：`backend/app/api/research.py:194-200`

**可能原因**：
- Nginx缓冲未禁用
- 网络不稳定
- 服务端超时

**解决**：
```python
# 确保响应头包含
headers={"X-Accel-Buffering": "no"}
```

### Q4: 如何修改LLM模型？

**配置文件**：`backend/.env`, `backend/app/config.py:30`

编辑 `backend/.env`：
```env
OPENROUTER_MODEL=openai/gpt-4o-mini:free
```

可用模型：https://openrouter.ai/models
